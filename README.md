# OpenPulse

An open-source Python toolkit for automated
dataset profiling and data quality analysis.

## Features

- CSV dataset ingestion
- Automated dataset profiling
- Missing value detection
- Unique value analysis
- Numeric data analysis
- Descriptive statistics

## Installation

Requires Python 3.

No external dependencies required.

## Usage

python openpulse.py dataset.csv

## Project Vision

OpenPulse aims to make data exploration
and statistical analysis more accessible
through lightweight, extensible tools.
